⚙️ 메인 주문생성 생성 규칙
  • Day를 설정하면 해당 Day에 활성화된 생성기·아이템만 대상으로 주문 생성
  • 생성기 제공 시점(fromDay_Node) ~ 은퇴 시점(untilDay_Node) 구간의 아이템만 등장
  • 고단계 아이템(10단계 이상)은 노드의 첫 번째 행에 배치되며, 9단계는 최대한 앞쪽 행(1~3행)에 배치
  • 같은 노드 안에서 고단계끼리는 서로 같은 행에 묶이지 않음 (난이도 급상승 방지)
  • 하드 아이템은 생성기 활성 기간의 75% 지점에 가장 많이 등장하도록 가중치 조정 (너무 이르면 등장 억제)
  • 새로운 생성기가 처음 등장하는 노드에서 해당 카테고리 아이템이 집중 배치 (설정 가능: 기본 2행)
  • 같은 카테고리가 연속으로 등장하지 않도록 행 간 카테고리 분산
  • 직전 노드 첫 행과 이번 노드 첫 행에 같은 아이템이 연속으로 나오지 않도록 방지
  • 노드 내 행 순서: 3칸 행(주문 3개)이 특정 구간에 몰리지 않도록 전체 구간에 고르게 분산
  • 노드 주문 개수(최소·최대 행 수) 설정 가능
  • 아이템 직접 추가·편집·삭제 가능 (세션 중 임시 적용)
🎲 중단랜덤 생성 규칙
  • 모든 아이템은 6단계 미만만 사용
  • 서로 다른 체인이라도 활성 구간이 겹치면 같은 행에 묶을 수 있음
  • 대상 아이템 전부 최소 1번 사용됨 (버려지는 아이템 없음)
  • 한 행의 골드 합계는 80 이하
  • 한 행에 하드 아이템은 최대 1개 (하드+하드 조합 금지)
  • 한 행에 같은 생성기 아이템은 1개까지만
  • 하드 단계 상한 · 하드 비율 상한 · 단계별 사용 비율 각각 조절 가능
  • 주문생성 체크된 생성기만 주문 1번 슬롯(주체)으로 뽑힘
  • 체크 해제된 생성기는 페어링 파트너로만 참여 가능
  • 커버리지(최소 1회 사용) 보장은 체크된 생성기만 대상
  • ⭐ 필수 포함 체크 시 해당 생성기가 반드시 포함, 활성 구간 겹치는 다른 생성기도 페어링 가능
📋 서브적체 A 생성 규칙
  • 기본은 6단계 미만만 사용, 하드는 단계 제한 없음 (전체 단계)
  • 기본은 기본적으로 제외 — 체크박스로 생성기별 선택 포함 가능 (하드는 항상 포함)
  • 서로 다른 체인이라도 활성 구간이 겹치면 같은 행에 묶을 수 있음
  • 포함된 전체 아이템 최소 1번 사용됨
  • 한 행 골드 합계는 골드 상한 이하 (기본 150, 조절 가능)
  • 한 행에 하드 아이템 최대 1개, 같은 생성기 아이템 1개까지만
  • 주문생성 체크된 생성기만 주문 1번 슬롯(주체)으로 뽑힘
  • 체크 해제된 생성기는 페어링 파트너로만 참여, 커버리지 보장도 제외
📊 서브적체 B 생성 규칙
  • 한 행에 고단계 아이템 정확히 1개 + 나머지는 저단계 필러 (고단계끼리 묶기 금지)
  • 필러는 활성 구간이 고단계 아이템과 겹치면 다른 체인이어도 사용 가능
  • 고단계 아이템 전부 최소 1번 사용됨
  • 골드 상한 없음 (가격 편차가 커서 미적용)
  • 한 행에 하드 아이템 최대 1개, 같은 생성기 아이템 1개까지만
  • 주문생성 체크된 생성기의 고단계 아이템만 앵커로 뽑힘
  • 체크 해제된 생성기는 저단계 필러로만 참여
  • 고단계 기준: 하드 원본 단계 ×1.3 반올림 적용 (하드 5단계 = 체감 7단계)
💳 결제유도 생성 규칙
  • 한 행에 고단계 아이템 정확히 1개 + 나머지는 저단계 필러 (고단계끼리 묶기 금지)
  • 고단계 기준: 기본 8단계 이상, 하드 5단계 이상
  • 저단계 필러: 기본 7단계 이하 · 하드 4단계 이하
  • 기본 고단계와 하드 고단계는 서로 같은 행에 묶이지 않음
  • 고단계 아이템 전부 최소 1번 사용됨
  • 골드 상한 없음
  • 한 행에 하드 아이템 최대 1개, 같은 생성기 아이템 1개까지만
  • 주문생성 체크된 생성기의 고단계 아이템만 앵커로 뽑힘
  • 하드 체크 해제 시 해당 생성기의 하드 아이템만 제외
🔄 반복 생성 규칙
  • 단계 제한 없이 전 단계 아이템 사용 (저단계~고단계 모두 포함)
  • 주문생성 체크된 생성기의 아이템만 주문의 주체(1번 슬롯)로 뽑힘
  • 체크 해제된 생성기는 직접 주문을 만들지 않지만, 활성 구간이 겹치면 페어링 파트너로 같은 행에 들어갈 수 있음
  • 커버리지(최소 1회 사용) 보장은 체크된 생성기만 대상
  • 서로 다른 체인이라도 활성 구간이 겹치면 페어링 가능
  • 한 행에 하드 아이템 최대 1개, 같은 생성기 아이템 1개까지만
  • 기본/하드 체크 해제 시 해당 생성기 아이템은 파트너로도 등장하지 않음
  • 단가가 골드 상한보다 비싼 아이템은 단독 행도 초과하므로 제외
